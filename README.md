# rag-citacoes-eval

> **Pilar do portfólio — Segunda** · parte de uma série de 7 projetos de Engenharia de Software de IA (1h/dia).

## O problema
Q&A sobre um corpus de documentos com busca híbrida (BM25 + densa), respostas com citação de fonte/página e avaliação medida (faithfulness, context recall).

## Por que está no portfólio
RAG híbrido com citações e tabela de avaliação (RAGAS). Recrutadores de IA em 2026 valorizam este pilar — e o diferencial é a **execução com avaliação medida**, não só a demo.
